# خطوات نشر نظام إدارة البدلاء على InfinityFree

## ما تحتاجه
- حساب مجاني على [InfinityFree](https://www.infinityfree.com)
- ملف `nizam_albadal_deploy.zip`

---

## الخطوة 1: إنشاء حساب InfinityFree

1. افتح [infinityfree.com](https://www.infinityfree.com)
2. اضغط **Sign Up**
3. أدخل بريدك الإلكتروني وكلمة سر
4. فعّل الحساب من البريد الإلكتروني

---

## الخطوة 2: إنشاء موقع جديد

1. سجّل الدخول على InfinityFree
2. من لوحة التحكم اضغط **Create Account**
3. اختر域名 مجاني (مثل: `badil-free.nf`)
4. اضغط **Create** — انتظر حتى يُنشأ الموقع

---

## الخطوة 3: إنشاء قاعدة بيانات MySQL

1. من لوحة التحكم اضغط على **MySQL Databases**
2. في حقل **Create New Database**:
   - اكتب اسم القاعدة: `badil`
   - اضغط **Create**
3. سجّل القيم الثلاثة التي تظهر:
   - **Database Name**: `a1234567_badil` (سيكون بناءً على اسم المستخدم)
   - **Database User**: `a1234567_badil`
   - **Database Password**: أدخل كلمة سر قوية واحفظها

---

## الخطوة 4: رفع الملفات

1. من لوحة التحكم اضغط **File Manager**
2. افتح مجلد `public_html`
3. اضغط **Upload** → اختر ملف `nizam_albadal_deploy.zip`
4. بعد الرفع، حدد الملف واضغط **Extract**
5. تأكد من أن الملفات موجودة في `public_html` مباشرة (وليس في مجلد فرعي)

---

## الخطوة 5: تعديل بيانات القاعدة

1. من File Manager افتح ملف `config.php`
2. غيّر هذه الأسطر الثلاثة:

```php
define('DB_NAME', 'YOUR_DB_NAME');   // ضع اسم القاعدة من الخطوة 3
define('DB_USER', 'YOUR_DB_USER');   // ضع اسم المستخدم من الخطوة 3
define('DB_PASS', 'YOUR_DB_PASS');   // ضع كلمة السر من الخطوة 3
```

**مثلاً:**
```php
define('DB_NAME', 'a1234567_badil');
define('DB_USER', 'a1234567_badil');
define('DB_PASS', 'MyStr0ngP@ssw0rd');
```

---

## الخطوة 6: تشغيل المُثبّت

1. افتح المتصفح وانتقل إلى:
   ```
   https://yourdomain.com/install.php
   ```
   (استبدل `yourdomain.com` بنطاقك الحقيقي)
2. أدخل بيانات حساب المسؤول:
   - اسم المستخدم: `admin`
   - كلمة السر: اختر كلمة سر قوية (6 أحرف على الأقل)
   - اسم المسؤول: اسمك
3. اضغط **تثبيت**
4. **احذف ملف install.php** بعد التثبيت

---

## الخطوة 7: تسجيل الدخول

1. افتح:
   ```
   https://yourdomain.com/index.php?page=login
   ```
2. سجّل الدخول بحساب المسؤول الذي أنشأته
3. من **المدارس والمستخدمون** أنشئ حسابات المدارس

---

## ملاحظات مهمة

### حسابات المدارس
- لكل مدرسة حساب برقم الهوية الوطني
- **اسم المستخدم** = رقم الهوية
- **كلمة السر** = رقم الهوية
- المدير يغيّر كلمة السر من قسم المستخدمين

### حساب المديرية
- أنشئ حساب من نوع **حساب مديرية** من قسم المستخدمين
- اختر الصلاحيات المناسبة (نهاية العمل، التكليف، التقارير)

### الشعار
- من الإعدادات → تبويب الشعار → ارفع شعار المديرية

### التحديث
- عند وجود نسخة جديدة، ارفع الملفات فوق القديمة (بدون حذف `uploads/`)
