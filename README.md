# نظام إدارة البدلاء — مديرية التربية والتعليم - يطا

تطبيق ويب احترافي متجاوب (يعمل من الهاتف والحاسوب) لإدارة ملف البدلاء في مدارس المديرية، مبني بلغة **PHP** وقاعدة بيانات **MySQL**، قابل للنشر على الاستضافة المشتركة أو أي سحابة.

---

## ✨ المزايا

| الميزة | التفاصيل |
|---|---|
| **ثلاثة أدوار** | مسؤول النظام · حساب مديرية · مدرسة |
| **حسابات المدارس** | اسم المستخدم = الرقم الوطني، وكلمة السر الافتراضية = الرقم الوطني، ويمكن لمسؤول النظام تغييرها |
| **طلبات البديل** | مدرسة الشاغر، مشترك مع مدارس، سبب الشاغر، مركز الشاغر، جنس الشاغر، بيانات الموظف الأصيل، المادة، الصفوف |
| **سجل البدلاء** | استيراد من ملف `Erecord.xlsx` بنفس ترتيب الأعمدة، الترتيب حسب نوع السجل ثم المعدل |
| **فلترة التكليف** | حسب الجنس والمبحث والاسم ورقم الهوية، مع زر اتصال وواتساب |
| **التكليف** | اختيار غير المكلفين فقط + نموذج إبداعي + توليد كتاب تكليف مرقّم تلقائياً |
| **إنهاء العمل** | تاريخ الإنهاء وعدد أيام العمل، وإعادة البديل لقائمة المتاحين |
| **الإعدادات** | ترويسة وتذييل الكتب المعتمدة، المباحث، الصفوف، أسباب الشاغر، المسميات |
| **التقارير** | 1) كتاب تكليف للعمل 2) تقرير بديل معين 3) تقرير جميع البدلاء 4) تقرير مدرسة محددة — كلها قابلة للطباعة PDF |

## 🚀 التشغيل محلياً (Docker)

```bash
docker compose up -d --build
```

- التطبيق: http://localhost:8080
- قاعدة البيانات: MySQL على المنفذ `3307`

عند أول تشغيل افتح `http://localhost:8080/install.php` وأنشئ حساب مسؤول النظام.

### بدون Docker (XAMPP / Laragon)

1. ضع المشروع في مجلد `htdocs`.
2. أنشئ قاعدة بيانات باسم `badil` واستورد `database.sql` عبر phpMyAdmin.
3. عدّل `config.php` ببيانات الاتصال.
4. افتح `http://localhost/app/index.php?page=install` (أو استيراد الـ SQL مباشرة).
5. احذف `install.php` بعد التثبيت.

> ملاحظة: يلزم تفعيل إضافات PHP: `pdo_mysql` و `mysqli` و `zip` و `xml`/`simplexml` (مفعلة افتراضياً في معظم الاستضافات).

## ☁️ النشر (الخيارات)

### 1) استضافة مشتركة (الأسهل — cPanel / Hostinger / GoDaddy)
- ارفع ملفات المشروع إلى `public_html`.
- أنشئ قاعدة بيانات MySQL من لوحة الاستضافة وعدّل `config.php`.
- استورد `database.sql` من phpMyAdmin، أو افتح `install.php`.
- احذف `install.php`.

### 2) سحابة عامة (VPS / PaaS)
- **VPS (DigitalOcean / Hetzner / Lightsail):** ثبّت LAMP (Apache + PHP 8 + MySQL) ثم انشر المشروع، أو استخدم الحاويات المرفقة:
  ```bash
  docker compose up -d
  ```
- **قاعدة بيانات سحابية:** تستخدم المنصة MySQL/MariaDB المتوافقة مع:
  - **Aiven for MySQL** (مجاني للبدء)
  - **Railway / Render MySQL**
  - **AWS RDS / GCP Cloud SQL** (للإنتاج الكبير)
  - عدّل `config.php` (أو متغيرات البيئة `DB_HOST`، `DB_NAME`، `DB_USER`، `DB_PASS`).

### 3) نشر سريع على Railway/Render
- ارفع المستودع إلى GitHub ثم أنشئ مشروع Web Service + MySQL، وضبط متغيرات البيئة الأربعة، وأمر التشغيل `docker compose up` أو `apache2-foreground`.

## 👥 الحسابات الافتراضية

| الدور | اسم المستخدم | كلمة السر | ملاحظة |
|---|---|---|---|
| مسؤول النظام | `admin` | تُحدد عند التثبيت | صلاحيات كاملة |
| حساب مديرية | يُنشئه المسؤول | يُحددها المسؤول | إنهاء الأعمال، الاتصال، الطباعة |
| مدرسة | الرقم الوطني | الرقم الوطني | تُستورد من ملف «المستخدمين وكلمات السر» |

> بعد الاستيراد، يمكن لمسؤول النظام من صفحة «المدارس والمستخدمون» تغيير أي كلمة سر.

## 📥 استيراد البيانات (من صفحة الإعدادات — مسؤول النظام)

1. **سجل البدلاء:** ملف `Erecord.xlsx` (يُحدّث دون فقدان سجلات العمل).
2. **المدارس:** ملف «المستخدمين وكلمات السر.xlsx» (اسم المدرسة، المستخدم، كلمة السر).
3. **المباحث:** ملف «المباحث.xlsx».

## 🔒 أمان

- كلمات السر مشفّرة بـ `password_hash()` (bcrypt).
- حماية CSRF لكل النماذج.
- جلسات آمنة مع إعادة توليد المعرّف عند الدخول.
- `.htaccess` يمنع الوصول إلى `config.php` و`database.sql` ومجلد `lib/` و`uploads/`.
- يوصى بـ **HTTPS** (شهادة Let's Encrypt مجانية على معظم الاستضافات).
- احذف `install.php` بعد التثبيت.
